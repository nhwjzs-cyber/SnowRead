# 融雪阅读 0.14.3 · 外观切换配色修复

版本code37，com.snowread.app与原开发签名保持。普通使用安装“融雪阅读-v0.14.3-debug.apk”，可覆盖更新，不清数据。

## 原因和修改

外观模式的 AppSheet 与 ChoiceStrip 使用创建时的主题/颜色。原先选择浅色仅重建了书架，仍显示的外观面板、分段按钮、文字与底板沿用深色。

此外，书架网格横板、封面卡片/列表、分类选中底色、分类拖动、多选删除等部分控件仍从 isNight()（阅读纸色）取色；即使首页明确选择浅色，若全局阅读纸色是夜读，这些控件仍画成深色。

本版在选中不同外观后，通过既有退出动画移除旧面板，保存选择、重建首页并重新打开新主题的外观面板。所选选项保留。相关书架控件统一使用 uiDark()；showLibrary() 同步更新 appearanceDark 缓存，防止回焦点时误判为旧外观再次重建。

阅读正文的纸色/夜读判断不变，没有修改天气数据、书库格式、阅读进度和签名。

## 验证范围

正式与隔离测试应用完成Java/资源/DEX构建、v1-v3签名、resources.arsc STORED+4字节对齐门禁。隔离仪器测试增加深→浅→深→浅→跟随的真实控件点击场景，刻意将阅读主题保持为夜读，检查首页底色、面板、分段按钮与外观缓存都遵循选择，阅读主题未变。测试已编译打包，未在手机/模拟器实际执行。

这次只改UI取色和外观面板刷新，不重复运行未变化的存储/核心套件。JAR关闭时已知沙箱AccessDenied诊断仍出现，编译退出0，后续DEX/签名/资源门禁成功。

## 手机验收

1. 首页更多→外观模式，先选深色，再选浅色。面板短暂过渡后重新出现，面板底板、按钮、文字与书架均为浅色；不需要重启。
2. 关闭面板检查分类、书架网格/列表、多选选中和删除按钮，再打开分类管理与导入预览。
3. 将阅读排版设为夜读，回书架选浅色，再检查上述UI不被阅读夜色影响。进书后仍是原来的夜读纸色。
4. 来回切深/浅/跟随；切后台后返回、重启应用，所选状态保持。跟随的解析策略沿用现有 ReaderPolicy，没有在本版重新定义。

隔离测试包只操作com.snowread.app.sandbox；不要用旧0.14.1仪器测试跑日常应用。自行构建和隔离操作沿用UPDATE-v0.14.2.md，替换文件名版本号即可。

源码归档不包含本机签名私钥dev/debug.keystore；自行构建沿用真实项目现有密钥。
