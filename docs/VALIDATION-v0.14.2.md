## 隔离自动测试（开发者）

仅测试时安装以下两个独立产物，不需要在日常应用里执行测试：

```text
adb -s <指定设备> install -r 融雪阅读-v0.14.2-隔离测试应用.apk
adb -s <指定设备> install -r 融雪阅读-v0.14.2-隔离仪器测试.apk
adb -s <指定设备> shell am instrument -w com.snowread.app.tests/com.snowread.app.FeatureInstrumentation
```

运行后可能保留测试书籍和设置，但仅在测试沙箱。确认instrumentation target为com.snowread.app.sandbox。不要使用旧测试APK或pm clear日常包。

自行构建：Build-WithSdk.ps1默认正式包；另以 -ApplicationId com.snowread.app.sandbox 和独立BuildRoot构建隔离App，再用其classes.jar调用Build-AndroidFeatureTests.ps1。两个构建当前共用项目根APK输出名，脚本执行者应分别复制命名，正式通用别名始终取正式APK。
