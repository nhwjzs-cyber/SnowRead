# 0.14.5 · 阅读转场闪烁修正

code39 / com.snowread.app / 原开发签名。

主题在showReader()里先解析再创建正文，已存在这一步；不能简单认定为“进阅读页后才加载设置”。本轮修正的是显示链路：

- 每次构建页面，将窗口与内容宿主底色同步为最终页面纸色，夜读不再露出固定浅纸窗口底色。
- 转场截图先填不透明底色，再捕获完整父容器，包含首页天气背景；不再只画透明的首页root。
- 新页面保持alpha=1，仅淡出旧截图，避免两个图层一起淡入淡出露出底色。
- 旧截图保留至新页面首次布局、进度恢复及分页准备完成；最长2秒安全退出等待。页面离开时取消监听与超时回调，避免旧转场影响新页面。
- 加载面板内部进度控件按UI外观取色，避免首页深色、阅读纸色尚未切换时混用浅色控件。

完成构建、签名和资源表门禁；本轮未在设备实际运行或观察闪烁，效果仍需同机录屏验收。建议首页深色→夜读、夜读返回书架、滚动/分页、长书定位、减少动效四组场景各反复打开10次。没有修改分页手势算法、书库数据和阅读排版设置。新增功能未包含在本修复包，见新增功能实施分期说明。

源码归档不含dev/debug.keystore，构建沿用原项目本地密钥。
