# 融雪阅读 · 「透明冰晶雪尘」动效改造方案

> 目标：把现在的“面板顶部 6 个几乎看不见的小冰晶”，改成 **透明、细腻、有冰晶质感的雪尘**。
> 原则：只做品牌氛围，不盖正文；透明、慢、稀疏、可关闭。

---

## 1. 现在为什么看不见

0.11.3 的 `SnowCrystalView` 实际参数：

- 只在部分 `AppSheet` 顶部 **44dp** 的一条带里绘制
- 6 个晶体，半径 **7–10dp**
- `Y = 13–18dp`，正好和标题、手柄、eyebrow 重叠
- 外层 alpha **60**，内层 alpha 235，但线宽只有 **1.05dp**
- 延迟 220ms 开始，总时长 **1100ms**
- 只播一次；打开面板后 1.3 秒就结束
- 书架、阅读页、目录、普通菜单根本没有

所以不是“没写”，而是写成了 **面板头部 1 秒的细线装饰**，肉眼很难捕捉。

---

## 2. 目标效果

### 2.1 关键词

**透明、细、慢、稀疏、冰晶质感、不抢字。**

不是“下雪”，是“空气里有很淡的冰晶尘埃”。

### 2.2 三层结构

| 层 | 内容 | 作用 |
|---|---|---|
| 底层 | 极淡冰蓝光晕 | 让雪尘有“空气感” |
| 中层 | 70% 微光尘点（1–2dp） | 主体，透明、细碎 |
| 上层 | 30% 微型六角冰晶（2.5–4.5dp） | 冰晶质感，不能太多 |

### 2.3 视觉参数

| 参数 | 书架背景 | 面板头部 |
|---|---|---|
| 粒子数 | 22 | 8 |
| 尺寸 | 1.1–4.2dp | 1.0–3.0dp |
| 透明度 | 0.10–0.30 | 0.15–0.35 |
| 下落速度 | 1.5–4.5dp/s | 1.0–2.0dp/s |
| 横向漂移 | ±2–8dp | ±1–4dp |
| 闪烁频率 | 0.1–0.3Hz | 0.1–0.2Hz |
| 帧率 | 30fps | 30fps |
| 覆盖 | <5% 像素 | <8% 头部区域 |

颜色：

- 日间：白色核心 `#F6FEFF` + 冰蓝边缘 `#8FD3E2` + 光晕 `#1F7EC8D8`
- 夜间：白色核心 `#D8F6FF` + 月光青边缘 `#8CD6E5` + 光晕 `#268CD6E5`

---

## 3. 放在哪里

### 推荐

1. **书架背景**：雪尘在卡片、标题、列表的**后面**，只从空白处透出来；不覆盖文字。
2. **AppSheet 顶部 48–56dp**：雪尘在面板头部飘，不进入正文区。
3. **空书架**：雪尘 + 单色雪融/新芽插画，作为品牌时刻。
4. **成功反馈**：导入/备份完成时，少量雪尘从顶部落下 1.2 秒，仅一次。

### 不推荐

- 阅读正文上持续飘雪：干扰阅读、耗电、低端机掉帧。
- 全屏铺满高密度雪点：像屏保，不像阅读器。
- 每个弹窗都飘：第一次新鲜，第三次烦。

---

## 4. 新增 `SnowDustView`

建议新增一个独立的 `SnowDustView`，替代/补充 `SnowCrystalView`。核心是：一个 View、固定粒子数、30fps、无对象分配、可暂停。

```java
package com.snowread.app;

import android.content.Context;
import android.graphics.*;
import android.os.SystemClock;
import android.view.View;
import java.util.Random;

/** Translucent ice dust. One view, bounded particles, 30fps, pauses when hidden. */
final class SnowDustView extends View {
    private static final int FRAME_MS = 33;
    private static final int MAX_PARTICLES = 24;

    private final Paint paint = new Paint(Paint.ANTI_ALIAS_FLAG);
    private final Path crystal = SnowCrystalView.crystalPath();
    private final Random random = new Random();
    private final Particle[] particles = new Particle[MAX_PARTICLES];
    private final boolean night;
    private final float density;

    private boolean running, initialized;
    private long lastFrame;
    private float time;
    private int count = 22;

    SnowDustView(Context context, boolean night) {
        super(context);
        this.night = night;
        this.density = getResources().getDisplayMetrics().density;
        setClickable(false);
        setFocusable(false);
        setImportantForAccessibility(IMPORTANT_FOR_ACCESSIBILITY_NO);
        setLayerType(View.LAYER_TYPE_HARDWARE, null);
        for (int i = 0; i < MAX_PARTICLES; i++) particles[i] = new Particle();
    }

    void setParticleCount(int value) {
        count = Math.max(0, Math.min(MAX_PARTICLES, value));
    }

    void start() {
        if (!Motion.enabled(getContext())) { running = false; invalidate(); return; }
        if (running) return;
        running = true;
        lastFrame = SystemClock.uptimeMillis();
        removeCallbacks(tick);
        postDelayed(tick, FRAME_MS);
    }

    void stop() {
        running = false;
        removeCallbacks(tick);
    }

    private final Runnable tick = new Runnable() {
        @Override public void run() {
            if (!running || !isShown()) return;
            invalidate();
            postDelayed(this, FRAME_MS);
        }
    };

    @Override protected void onSizeChanged(int w, int h, int oldw, int oldh) {
        super.onSizeChanged(w, h, oldw, oldh);
        init(w, h);
    }

    private void init(int w, int h) {
        if (w <= 0 || h <= 0) return;
        initialized = true;
        time = 0;
        for (Particle p : particles) p.reset(random, w, h, density, true);
    }

    private void update() {
        long now = SystemClock.uptimeMillis();
        float dt = Math.min(0.05f, (now - lastFrame) / 1000f);
        lastFrame = now;
        time += dt;
        int w = getWidth(), h = getHeight();
        if (w <= 0 || h <= 0) return;
        for (int i = 0; i < count; i++) {
            Particle p = particles[i];
            p.y += p.speed * dt;
            if (p.y > h + dp(8)) p.reset(random, w, h, density, false);
            p.drawX = p.baseX + (float) Math.sin(time * p.freq + p.phase) * p.amp;
            p.rot += p.rotSpeed * dt;
        }
    }

    @Override protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);
        if (!initialized) init(getWidth(), getHeight());
        boolean motion = Motion.enabled(getContext());
        if (running && motion) update();

        for (int i = 0; i < count; i++) {
            Particle p = particles[i];
            float twinkle = motion
                    ? 0.72f + 0.28f * (float) Math.sin(time * p.twinkle + p.phase)
                    : 1f;
            float alpha = p.alpha * twinkle;
            drawHalo(canvas, p.drawX, p.y, p.size, alpha);
            if (p.crystal) drawCrystal(canvas, p.drawX, p.y, p.size, alpha, p.rot);
            else drawDust(canvas, p.drawX, p.y, p.size, alpha, p.rot);
        }
    }

    private void drawHalo(Canvas canvas, float x, float y, float r, float a) {
        paint.setStyle(Paint.Style.FILL);
        paint.setColor(night ? 0x1A8CD6E5 : 0x145FA9B8);
        paint.setAlpha(Math.round(255 * a * 0.55f));
        canvas.drawCircle(x, y, r * 3.4f, paint);
        paint.setColor(night ? 0x268CD6E5 : 0x1F7EC8D8);
        paint.setAlpha(Math.round(255 * a * 0.8f));
        canvas.drawCircle(x, y, r * 1.9f, paint);
    }

    private void drawCrystal(Canvas canvas, float x, float y, float r, float a, float rot) {
        canvas.save();
        canvas.translate(x, y);
        canvas.rotate(rot);
        canvas.scale(r, r);
        paint.setStyle(Paint.Style.STROKE);
        paint.setStrokeCap(Paint.Cap.ROUND);
        paint.setStrokeJoin(Paint.Join.ROUND);
        paint.setStrokeWidth(Math.max(0.6f, 0.9f) / r);
        paint.setColor(night ? 0xFFD8F6FF : 0xFFF6FEFF);
        paint.setAlpha(Math.round(255 * Math.min(1f, a * 2.2f)));
        canvas.drawPath(crystal, paint);
        paint.setColor(night ? 0xFF8CD6E5 : 0xFF8FD3E2);
        paint.setAlpha(Math.round(255 * Math.min(1f, a * 1.4f)));
        canvas.drawPath(crystal, paint);
        canvas.restore();
    }

    private void drawDust(Canvas canvas, float x, float y, float r, float a, float rot) {
        canvas.save();
        canvas.translate(x, y);
        canvas.rotate(rot);
        paint.setStyle(Paint.Style.STROKE);
        paint.setStrokeCap(Paint.Cap.ROUND);
        paint.setStrokeWidth(Math.max(0.5f, 0.7f));
        paint.setColor(night ? 0xFFD8F6FF : 0xFFF8FEFF);
        paint.setAlpha(Math.round(255 * Math.min(1f, a * 2.5f)));
        canvas.drawLine(-r, 0, r, 0, paint);
        canvas.drawLine(0, -r, 0, r, paint);
        canvas.restore();
    }

    private float dp(float value) { return value * density; }

    @Override protected void onAttachedToWindow() {
        super.onAttachedToWindow();
        if (isShown()) start();
    }

    @Override protected void onDetachedFromWindow() {
        stop();
        super.onDetachedFromWindow();
    }

    @Override protected void onVisibilityChanged(View changed, int visibility) {
        super.onVisibilityChanged(changed, visibility);
        if (visibility == VISIBLE) start(); else stop();
    }

    @Override protected void onWindowVisibilityChanged(int visibility) {
        super.onWindowVisibilityChanged(visibility);
        if (visibility == VISIBLE) start(); else stop();
    }

    private static final class Particle {
        float baseX, drawX, y, size, alpha, speed, amp, freq, phase, twinkle, rot, rotSpeed;
        boolean crystal;

        void reset(Random random, int w, int h, float density, boolean initial) {
            baseX = random.nextFloat() * w;
            drawX = baseX;
            y = initial ? random.nextFloat() * h : -8 * density;
            size = (1.1f + random.nextFloat() * 3.1f) * density;
            alpha = 0.10f + random.nextFloat() * 0.20f;
            speed = (1.5f + random.nextFloat() * 3.0f) * density;
            amp = (2f + random.nextFloat() * 6f) * density;
            freq = 0.08f + random.nextFloat() * 0.18f;
            phase = random.nextFloat() * (float) (Math.PI * 2);
            twinkle = 0.10f + random.nextFloat() * 0.20f;
            rot = random.nextFloat() * 360f;
            rotSpeed = (random.nextFloat() - 0.5f) * 8f;
            crystal = random.nextFloat() < 0.35f;
        }
    }
}
```

要点：

- 70% 是 1–2dp 的光尘（十字星），30% 是 2.5–4.5dp 的六角冰晶。
- 光晕用两层圆，不用 `BlurMaskFilter`，避免性能问题。
- 全部粒子 alpha 0.10–0.30，整体透明。
- 只在 `onDraw` 中更新，30fps，无每帧对象分配。
- 隐藏/后台/Detached 自动停。
- 减少动效时只画一帧静态雪尘，不播放。

## 5. 接入书架背景

当前 `MainActivity.frame(false)` 是：

```java
root = new LinearLayout(this);
root.setOrientation(LinearLayout.VERTICAL);
root.setBackgroundColor(bg);
setContentView(root);
EdgeToEdge.listen(root, reading, ...);
```

改成书架模式时加一个背景层：

```java
private SnowDustView shelfDust;

private void frame(boolean reading) {
    colors(reading);
    if (!reading) {
        FrameLayout stage = new FrameLayout(this);
        stage.setBackgroundColor(bg);

        shelfDust = new SnowDustView(this, isNight());
        shelfDust.setTag("shelf-snow-dust");
        stage.addView(shelfDust, new FrameLayout.LayoutParams(-1, -1));

        root = new LinearLayout(this);
        root.setOrientation(LinearLayout.VERTICAL);
        root.setBackgroundColor(Color.TRANSPARENT);
        stage.addView(root, new FrameLayout.LayoutParams(-1, -1));
        setContentView(stage);

        EdgeToEdge.listen(root, false, (left, top, right, navigation, keyboard) ->
                root.setPadding(left, top, right, Math.max(navigation, keyboard)));
    } else {
        shelfDust = null;
        root = new LinearLayout(this);
        root.setOrientation(LinearLayout.VERTICAL);
        root.setBackgroundColor(bg);
        setContentView(root);
        EdgeToEdge.listen(root, true, ...);
    }
}
```

注意：

- 雪尘放在 `root` **下面**，不盖正文/卡片/文字，只从背景和空白处透出。
- `root` 背景透明，`stage` 负责纸色背景。
- 阅读页 `reading == true` 不创建雪尘。
- `showLibrary()` 重建时旧 `shelfDust` 随旧 View detach 自动 stop。

## 6. 接入 AppSheet 头部

当前 `AppSheet` 用 `SnowCrystalView` 44dp。建议替换成 `SnowDustView`：

```java
private SnowDustView snow; // 原来是 SnowCrystalView

if (spec.snowflakes) {
    FrameLayout decorated = new FrameLayout(getContext());
    decorated.addView(panel, new FrameLayout.LayoutParams(-1, -2));

    snow = new SnowDustView(getContext(), spec.dark);
    snow.setParticleCount(8);
    snow.setTag("sheet-snow-dust");
    decorated.addView(snow, new FrameLayout.LayoutParams(-1, dp(56), Gravity.TOP));

    column.addView(decorated, new LinearLayout.LayoutParams(-1, -2));
}
```

打开时：

```java
if (snow != null) snow.start(); // 替换原来的 playAfter
```

关闭时：

```java
if (snow != null) snow.stop();
```

建议：

- 面板头部 56dp，雪尘只在头部，不进入正文。
- 如果担心盖住标题，把 `snow` 放在 `panel` **下面**（先 add panel，再 add snow 就是覆盖；先 snow 后 panel 会被面板背景盖住）。更稳的是给 `panel` 顶部加 8–12dp padding，让雪尘在标题上方的留白里。
- 或者只把雪尘放在面板**左右上角**：通过 `snow.setPadding` / 自定义绘制区域，避免标题中线。

## 7. 成功反馈的“雪落一瞬”

导入/备份完成时，不要全屏，做一个 1.2 秒的局部雪落：

- 12 个粒子
- 从面板顶部 0 落到 40dp
- alpha 0→0.8→0
- 只在成功汇总时触发一次

可以复用 `SnowDustView` 加一个 `burst` 模式，或保留 `SnowBurst` 但把半径从 6dp 提到 10dp、时长从 900ms 提到 1100ms。

## 8. 性能与无障碍

- 粒子数上限 24，书架默认 22，面板 8。
- 30fps，不是 60fps；`postDelayed(33)`。
- `onDraw` 不分配对象；`Path` 复用；光晕用圆，不用模糊。
- `onVisibilityChanged` / `onWindowVisibilityChanged` / `onDetachedFromWindow` 停止。
- 粒子不点击、不焦点、不进入无障碍树。
- `Motion.enabled == false`（减少动效/系统关闭动画/TalkBack）时只画静态一帧，不播放。
- 阅读正文不叠加雪尘，避免影响对比度。
- 纸色背景上雪尘 alpha 不要超过 0.35；超过会像脏点。
- 夜间可以比日间略高一点，但不要发光过强。

## 9. 验收标准

- [ ] 打开书架 2 秒内能明显看到缓慢漂移的雪尘，但不会误认为屏幕脏点。
- [ ] 截图 1s 和 4s 粒子位置不同，证明在动。
- [ ] 文字/封面/按钮上没有被雪尘遮挡，正文对比度不变。
- [ ] 30 分钟书架停留无掉帧、无明显发热/耗电。
- [ ] 切后台/锁屏/旋转后自动暂停，回来恢复。
- [ ] 减少动效/系统动画关闭/TalkBack 时无动画，只保留静态或完全关闭。
- [ ] 面板头部雪尘不盖标题、不挡按钮。
- [ ] `dumpsys gfxinfo` 无持续掉帧；`adb shell screenrecord` 可肉眼确认。

---

## 10. 建议实施顺序

1. **只做书架背景**：22 粒子，1–4dp，alpha 0.10–0.30，30fps。先确认“看得见但不脏”。
2. **再做 AppSheet 头部**：8 粒子，56dp，透明。
3. **最后做成功反馈**：12 粒子，1.2s，一次性。
4. 阅读页不加持续雪尘；最多章节切换时 1.2s 轻微雪尘。

---

## 11. 一句话

**把“6 个大冰晶在标题上闪 1 秒”改成“22 个 1–4dp 的半透明冰晶尘埃在书架背景里慢慢飘，30fps、可暂停、不盖字”。**  
这样才有“雪尘”的透明感和冰晶质感，而不是一块看不清的装饰。
