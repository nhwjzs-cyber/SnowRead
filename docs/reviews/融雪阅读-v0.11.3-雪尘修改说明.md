# 融雪阅读 0.11.3 · 弹窗冰晶雪尘修改说明

## 1. 这次改了什么

把原来的“面板顶部 44dp、6 个冰晶、1.1 秒消失”的装饰，改成 **一次性的、半透明的冰晶雪尘**：

- 14 个粒子
- 70% 微光尘点，30% 微型六角冰晶
- 尺寸 1.0–3.6dp
- 透明度 0.10–0.26
- 缓慢向外/向下飘散 6–16dp
- 时长 1.7 秒
- 只播一次，不循环
- 面板头部 56dp，不进入正文
- 不在阅读页、书架正文、列表上覆盖

### 视觉

- 日间：白色尘点 + 冰蓝边缘 + 很淡的青色光晕
- 夜间：白色/月光青 + 淡青光晕
- 所有粒子都是半透明，不会出现一块实心白

## 2. 已启用雪尘的弹窗

这次不仅保留原来的分类/数据/排版等面板，还把以下常用弹窗接入了：

- 书架“更多操作”
- 书籍长按菜单
- 阅读页“更多选项”
- 目录
- 输入章号跳转
- 书签列表
- 正文搜索
- 分类选择/分类管理/新建分类
- 备份与数据管理
- 阅读排版
- 听书偏好
- 导入/备份完成成功页

删除确认、覆盖恢复、清空回收站等破坏性确认仍然不启用，避免在危险操作上做装饰。

## 3. 实现位置

### `SnowCrystalView.java`

原文件被重写为“尘埃”实现，但保留：

- `crystalPath()`
- `opacity()`
- `drawCrystal()`
- `playAfter()` / `play()` / `stop()` / `animating()`

因此 `SnowBurst`、`AppSheet` 和现有测试的类名/方法不变。

核心参数：

```java
static final long DURATION = 1700;
private static final int COUNT = 14;
p.size  = dp(1.0f + random.nextFloat() * 2.6f);
p.alpha = .10f + random.nextFloat() * .16f;
p.vx    = (random.nextFloat() - .5f) * dp(16);
p.vy    = dp(2.5f + random.nextFloat() * 7);
```

### `AppSheet.java`

- 雪尘高度从 44dp 改为 **56dp**
- 仍然在面板顶部、标题上方区域绘制
- 打开面板后 220ms 开始
- 关闭/下滑时立即 stop

### `MainActivity.java`

给以下 `dialog()` 加了 `.setSnowflakes(true)`：

- `shelfMenu()`
- `bookOptions()`
- `readerOptions()`
- `chapters()`（目录）
- `chapterJump()`
- `bookmarks()`
- `search()`

已有的分类/数据/排版/成功页保持。

## 7. 如果太淡/太明显，怎么调

只改 `SnowCrystalView.java`：

| 想要 | 改法 |
|---|---|
| 更明显 | `COUNT = 18`，`alpha = .14f + ... .24f` |
| 更淡 | `COUNT = 10`，`alpha = .08f + ... .14f` |
| 更慢 | `DURATION = 2200`，`vy` 降到 `dp(1.5f + ...4)` |
| 粒子更大 | `size = dp(1.4f + ...3.0f)` |
| 粒子更小 | `size = dp(0.8f + ...2.0f)` |
| 更偏冰晶 | `p.crystal = random.nextFloat() < .45f` |
| 更偏尘埃 | `p.crystal = random.nextFloat() < .20f` |

建议先保持当前参数；如果手机上几乎看不见，再把 `COUNT` 提到 18、`alpha` 上限提到 .32；如果觉得“太花”，降到 10 个、alpha 上限 .18。
