## 0. 使用说明

### 优先级

| 级别 | 含义 |
|---|---|
| **P0** | 下一版必须做；影响每天阅读或数据安全 |
| **P1** | 0.9 系列应做；高价值、成本可控 |
| **P2** | 后续版本；有价值但可以排期 |
| **P3** | 探索/锦上添花；暂不承诺 |

### 工作量

| 标记 | 含义 |
|---|---|
| **S** | 0.5 天以内 |
| **M** | 0.5–2 天 |
| **L** | 3–5 天 |
| **XL** | 5 天以上 / 需要专项 |

### 状态

- `[ ]` 未开始
- `[~]` 进行中
- `[x]` 已完成
- `[!]` 阻塞/待决策

## 2. P0：下一版必须做

### R-01 阅读页亮度调节

- [ ] **P0 / S** 增加亮度滑条 + “跟随系统”开关
  - 使用 `WindowManager.LayoutParams.screenBrightness`，范围 0.01–1.0；`-1` 跟随系统
  - 存入 `SharedPreferences`，在 `showReader` / `onResume` 应用
  - 离开阅读页时恢复 `-1`
  - 验收：夜间阅读不需要退出 App 调系统亮度；重启后保留
  - 位置：`MainActivity.appearance`、`applyAwake`、`showReader`

### R-02 小字对比度

- [ ] **P0 / S** 提高 11sp 青蓝文字的对比度
  - 当前 `#248FA9` on `#F3EDE0` ≈ 3.23:1，低于 WCAG AA 4.5:1
  - 小字改用 `#0F5F73` / `#14657A`，`#248FA9` 只用于图标/大字号
  - 验收：导航文字、分类 chips、tagline 在低亮度/户外可读
  - 位置：`SnowTheme`、`navButton`、`addCategoryChip`

### D-01 精确恢复，而不只是合并

- [ ] **P0 / M** 增加“覆盖恢复（会删除当前书架中备份没有的书）”
  - 二次确认，明确写出会删除哪些书/分类
  - 调用 `BackupArchive.restore(..., merge=false)` 或新增 replace 分支
  - 保留“合并”作为默认安全选项
  - 验收：从备份恢复后书架与备份完全一致
  - 位置：`inspectBackup`、`restoreBackup`

### D-02 书籍移出撤销/回收站

- [ ] **P0 / M** 移出书籍后 5 秒内可撤销
  - 先移入内存/回收站，计时结束再删文件
  - 或回收站保留 7 天，设置里可清理
  - 验收：误删后可恢复正文、封面、进度、书签
  - 位置：`LibraryStore.remove`、`bookOptions`

### D-05 长任务可取消

- [ ] **P0 / S** 备份/恢复/导出时提供进度和取消
  - 当前 `busy` 时返回键无效
  - 至少允许返回键弹“正在恢复，是否取消？”
  - 进度条用 determinate；无法确定总量时用 indeterminate 线
  - 验收：恢复中断后原书库完好，可重试

### I-04 TXT 清洗/重排

- [ ] **P1 / S** 连续空行压缩、行尾空白清理
- [ ] **P1 / M** 处理结果必须预览；原始文件不改
  - 验收：硬换行 TXT 合并后段落自然；广告行可批量删除

### I-05 “继续阅读”卡片

- [ ] **P1 / S** 书架顶部显示“继续阅读《书名》· 第 x 章 · 42%”
