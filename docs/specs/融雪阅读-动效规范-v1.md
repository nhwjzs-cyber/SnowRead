# 融雪阅读 · 动效规范 v1.0

适用范围：Android 0.7+，书架、阅读页、底部面板、Toast、批量导入、备份/恢复、搜索。
目标：用最少的动效解释“从哪里来、发生了什么、还要多久”，不做装饰性动画。

---

## 1. 总原则

1. **只做三类动效**
   - 空间关系：面板从底部来、工具栏从边缘来、页面之间切换。
   - 操作确认：按下去有反馈、添加书签有提示、导入完成有结果。
   - 进度表达：批量导入、备份、恢复必须让用户看到“在动”。
2. **安静**：不弹跳、不旋转、不闪烁、不做持续背景动画。
3. **快**：120 / 180 / 220 / 240ms 四档，超过 240ms 必须有明确理由。
4. **可关闭**：系统关闭动画、TalkBack 触摸探索、用户开启“减少动效”时，全部直接切到最终状态。
5. **只动 alpha / translation / scale**：不动画 width、height、margin，避免每帧 layout。
6. **复用优先**：8 个场景只新增 5 个原语，不分别为每个页面写动画。

---

## 2. 动效令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `FAST` | 120ms | 按压、徽标、文字切换、进度填充 |
| `BASE` | 180ms | 工具栏、Toast、搜索结果、开书/退书、主题切换 |
| `SHEET` | 220ms | 底部面板入场 |
| `PAGE` | 240ms | 翻页（现有，不调整） |
| `EASE_IN` | `DecelerateInterpolator(1.4f)` | 入场、出现 |
| `EASE_OUT` | `AccelerateInterpolator(1.2f)` | 退场、消失 |
| `EASE_STD` | `FastOutSlowInInterpolator` | 交叉淡入、面板（可选） |
| `NUDGE` | 8dp | 工具栏上下位移 |
| `SHEET_IN` | 32dp | 底部面板入场位移 |
| `SHEET_OUT` | 16dp | 底部面板退场位移 |
| `TOAST_IN` | 12dp | Toast 入场位移 |
| `TOAST_OUT` | 6dp | Toast 退场位移 |
| `CONTENT_NUDGE` | 4dp | 阅读页、搜索结果淡入位移 |
| `SCRIM` | 0.32 | 底部面板遮罩透明度 |
| `PRESS_SCALE` | 0.97 | 书架卡片按下缩放 |

## 3. 可复用原语

新增一个 `com.snowread.app.Motion` 工具类，所有页面只调用下面 5 个原语。

### 3.1 `enter` / `exit`：位移 + 淡入淡出

```java
static void enter(View v, float fromYDp) {
    // alpha 0 -> 1，translationY fromYDp -> 0
    // BASE，EASE_IN
}

static void exit(View v, float toYDp, Runnable endAction) {
    // alpha 1 -> 0，translationY 0 -> toYDp
    // BASE 或 FAST，EASE_OUT
    // 结束后执行 endAction
}
```

使用方式：

- 底部面板：`fromYDp = SHEET_IN`，`toYDp = SHEET_OUT`
- 顶部工具栏：`fromYDp = -NUDGE`；底部工具栏：`fromYDp = +NUDGE`
- Toast：`fromYDp = TOAST_IN`，`toYDp = TOAST_OUT`
- 阅读页/搜索结果：`fromYDp = CONTENT_NUDGE`

### 3.2 `press` / `release`：按压缩放

```java
static void press(View v) {
    // scaleX/scaleY 1 -> 0.97，FAST，EASE_OUT
}

static void release(View v) {
    // scaleX/scaleY -> 1.0，FAST，EASE_IN
}
```

只用于书架卡片、书籍封面等“可点击的大块目标”。按钮已有 ripple，不重复加缩放。

### 3.3 `crossFade`：两个界面的交叉淡入

```java
static void crossFade(View out, View in, long duration) {
    // out alpha 1 -> 0，in alpha 0 -> 1
    // BASE，EASE_STD
    // 可选：in 从 CONTENT_NUDGE 上移到 0
}
```

用于开书/退书、主题切换、搜索提示切换为结果列表。

### 3.4 `progress`：进度条数值动画

```java
static void progress(ProgressBar bar, int value) {
    // ObjectAnimator 120ms，EASE_OUT
    // 减少动效时直接 setProgress(value)
}
```

用于批量导入、备份导出、恢复进度。只使用 determinate 进度条；无法确定总量时才用 indeterminate 进度线。

### 3.5 `sheetIn` / `sheetOut`：底部面板专用

```java
static void sheetIn(View panel, Window window) {
    // panel: alpha 0.92 -> 1，translationY SHEET_IN -> 0
    // 220ms，EASE_IN
    // window dim: 0 -> SCRIM，180ms
}

static void sheetOut(View panel, Window window, Runnable endAction) {
    // panel: alpha 1 -> 0，translationY 0 -> SHEET_OUT
    // 160ms，EASE_OUT
    // window dim: SCRIM -> 0
    // 结束后 endAction
}
```

`sheetIn/out` 内部复用 `enter/exit` + 一个 `ValueAnimator` 控制 `window.setDimAmount`，不要单独写第二套。

### 3.6 统一开关

```java
static boolean enabled(Context context) {
    // 1. ValueAnimator.areAnimatorsEnabled()
    // 2. !AccessibilityManager.isTouchExplorationEnabled()
    // 3. prefs.getBoolean("reduceMotion", false) == false
}
```

所有原语入口先判断 `enabled`；关闭时直接设置最终值，不延迟、不回调动画。

## 4. 组件对照表：在哪里加、加什么

| 优先级 | 场景 | 触发位置 | 具体效果 | 复用原语 |
|---|---|---|---|---|
| P0 | **底部面板 AppSheet** | `AppSheet.show()` / `onCreate()` / `dismiss()` | 面板从底部 32dp 滑入 + alpha 0.92→1，220ms；遮罩 0→0.32，180ms；退场 16dp + 淡出，160ms | `sheetIn/out` |
| P0 | **批量导入进度** | `MainActivity.startBatchImport()`、`BatchImporter.Progress` | 3dp determinate 进度条，120ms 填充；文件名 120ms 交叉淡入；完成勾选 0.8→1，180ms | `progress` + `enter` |
| P0 | **备份/恢复进度** | `MainActivity.exportBackup()` / `restoreBackup()`、`BackupArchive.Progress` | 同上；无法确定总量时用 2dp indeterminate 线；不要全屏转圈 | `progress` + `enter` |
| P0 | **工具栏显隐** | `MainActivity.applyChromeVisibility()` | 顶部栏 alpha + 0→-8dp；底部栏 alpha + 0→+8dp；显示反向；180ms | `enter/exit` |
| P0 | **Toast** | `MainActivity.toast()` | 从底部 12dp 滑入 + 淡入，180ms；退场向下 6dp + 淡出，120ms；3.2 秒停留 | `enter/exit` |
| P1 | **书架卡片按压** | `ShelfAdapter.getView()` 的 `tile` | 按下 scale 0.97，120ms；抬起回 1.0，120ms；多选徽标 0.9→1，120ms | `press/release` |
| P1 | **开书/退书** | `MainActivity.openBook()` / `leaveReader()` | 书架淡出 120ms；阅读页淡入 + 4dp 上移，180ms；退书反向 | `crossFade` |
| P2 | **搜索结果出现** | `MainActivity.search()`、`MainActivity$7` | 结果列表整体淡入 + 4dp 上移，180ms；不要逐行 stagger；搜索中用 2dp 进度线 | `enter` + `progress` |
| P2 | **主题切换** | `appearance()` 的 `onDismiss` → `showReader()` | 旧阅读页截图覆盖，180ms 淡出；不要逐帧插值文字颜色 | `crossFade` |

### 4.1 翻页动效：保持现状

`PagedReaderView.startTransition()` 已经是 240ms 左右滑动 + 边界线，体验稳定。**本次规范不修改翻页**。

如果以后要加“覆盖”模式：新页从右侧 100%→0，200ms，旧页不动；仿真卷曲最后做，不作为第一版目标。

## 5. 复用关系：5 个原语覆盖 8 个场景

| 原语 | 使用场景 | 说明 |
|---|---|---|
| `enter/exit` | 底部面板、工具栏、Toast、搜索结果、阅读页 | 最通用，占新增代码约一半 |
| `press/release` | 书架卡片 | 只写一处，所有卡片复用 |
| `crossFade` | 开书/退书、主题切换、搜索提示→结果 | 两个 View 的通用过渡 |
| `progress` | 批量导入、备份、恢复 | 所有长任务共用 |
| `sheetIn/out` | AppSheet | 面板专用，内部复用 `enter/exit` |

**预期新增代码：`Motion.java` 约 120–150 行；各页面只加 1–3 行调用。** 不引入 Lottie、不新增依赖、不改布局 XML。

## 6. 接入位置清单（按文件）

| 文件/类 | 改动 |
|---|---|
| `Motion.java` | 新增 5 个原语 + `enabled()` + 令牌常量 |
| `AppSheet.java` | 保存 `sheetPanel` 字段；`show()` 调 `sheetIn`；`dismiss()` 调 `sheetOut`；可选手柄拖拽 |
| `MainActivity.java` | `applyChromeVisibility` 加位移；`toast` 加入场/退场；`startBatchImport` 加进度条；`exportBackup/restoreBackup` 加进度；`openBook/leaveReader` 加交叉淡入；`search` 结果列表淡入 |
| `ShelfAdapter`（MainActivity 内部类） | `tile` 加 `press/release`；`getView` 复用时重置 scale |
| `PagedReaderView.java` | 不改；保留现有 240ms 翻页 |
| `res/values/styles.xml` | 可选：给 `SnowDialogLight/Dark` 配 `windowAnimationStyle`；若手动调 `sheetIn/out` 则不需要 |

## 7. 减少动效与无障碍

以下任一条件成立时，所有原语直接落到最终状态：

- `ValueAnimator.areAnimatorsEnabled() == false`
- 系统“动画时长缩放”为 0
- `AccessibilityManager.isTouchExplorationEnabled() == true`
- 用户在设置中开启“减少动效”

额外要求：

- 动画不能是唯一反馈：书签添加仍有 Toast 文案，导入完成仍有汇总文字。
- 不改变内容描述、焦点顺序、点击区域。
- 大字体、深色模式、横屏下效果一致；横竖屏切换时取消动画，不重播。

## 8. 性能与稳定性

1. 只使用 `ViewPropertyAnimator` / `ValueAnimator`，不使用 `LayoutTransition` 或 `animateLayoutChanges`。
2. 列表只动容器，不动每一行；`getView` 复用时重置 `translationY/alpha/scale`。
3. 动画前 `cancel()` 同一 View 上的旧动画；快速连点不会叠加。
4. `onPause`、`onDetachedFromWindow`、Dialog dismiss 时取消动画。
5. `AppSheet` 动画期间可给 panel 加 `LAYER_TYPE_HARDWARE`，结束后恢复 `LAYER_TYPE_NONE`。
6. 60Hz/120Hz 都按毫秒计时，不按帧数；低端机允许丢 1–2 帧，但不能卡顿。
7. 不新增权限、不新增第三方库、不增加 APK 资源体积。

## 9. 验收清单

- [ ] 底部面板从底部进入，退场向下；遮罩同步渐变，不先黑一下。
- [ ] 批量导入 500 个文件时，进度条持续前进，文字切换不闪。
- [ ] 备份/恢复的进度条与文字同步，不会出现“卡住”的观感。
- [ ] 工具栏隐藏/显示有 8dp 方向感，正文区域不移动。
- [ ] Toast 不叠加，新 Toast 替换旧 Toast。
- [ ] 书架卡片按下/抬起有反馈，滚动时不误触发。
- [ ] 开书/退书是 180ms 交叉淡入，不闪白。
- [ ] 搜索结果整体淡入，不逐行闪烁。
- [ ] 系统关闭动画/TalkBack/减少动效时，全部立即完成。
- [ ] 快速连点、旋转屏幕、返回键中断时无崩溃、无残留动画。
- [ ] 翻页动画保持现状，未被新动效干扰。

## 10. 落地顺序

| 阶段 | 内容 | 预估 |
|---|---|---|
| Phase 1（P0） | `Motion.java` + AppSheet + 批量/备份进度 + 工具栏 + Toast | 0.5–1 天 |
| Phase 2（P1） | 书架按压 + 开书/退书 | 0.5 天 |
| Phase 3（P2） | 搜索结果淡入 + 主题切换（可选） | 0.5 天 |

**建议先做 Phase 1。** 这 5 个场景覆盖了用户每天最常看到的界面变化，且全部复用同一套原语；Phase 2/3 只是锦上添花。

---

## 11. 一句话标准

> 动效只解释空间、确认操作、表达进度；全部走 `FAST/BASE/SHEET/PAGE` 四档和 `enter/exit/press/crossFade/progress` 五个原语；系统关闭动画时立即完成；阅读正文保持静止。
