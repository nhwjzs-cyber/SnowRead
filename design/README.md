# 融雪阅读 0.5 · 纸色与初春

## 图标

保留 0.4 的六角平涂雪花、细浅冰蓝边线与中心切面。雪花整体倾斜 -12°，横向轻压至 94%，用轻微角度变化表现侧向感，保持矢量平涂，不增加写实材质。

背景改为中等明度春绿 #528F80，配合浅绿地面与一枝新芽。白雪与嫩芽前后相接，呼应“融雪”从冬到春的意象。传统图标保留圆角裁切；自适应图标将新芽场景放在独立背景层；单色图标保留倾斜雪花轮廓。

## 纸色背景、冷色交互

| 用途 | 颜色 |
|---|---|
| 书架 / 主页面纸色 | #F3EDE0 |
| 默认阅读原纸 | #F8F2E8 |
| 暖纸 | #F0E5D1 |
| 卡片 / 浅色浮层 / 弹窗 | #FFFCF5 |
| 按钮、选中项和交互文字 | #19768E |
| 轻强调底色 | #E2F3F6 |
| 主文字 | #193E4B |
| 次要文字 | #506873 |
| 界面描边 | #D6E2E4 |

青蓝色的按钮、导航图标、单选框、进度条和点击反馈继续保留；书架、默认阅读页、卡片及浅色弹窗改用不同深浅的纸色。夜读沿用深色主题及已有用户选择。样式集中在 SnowTheme.java 与 res/values/styles.xml 中。

## 文件

- ic_spring_background.xml：春绿地面与新芽。
- ic_snowread_foreground.xml：倾斜后的雪花。
- ic_leaf.xml：传统图标，包含完整场景和圆角裁切。
- ic_snowread_monochrome.xml：单色主题轮廓。
- Render-Icon.ps1：从当前矢量资源渲染本预览，支持路径曲线与分组变换。

应用显示名称为“融雪阅读”，内部包名继续使用 com.snowread.app，以便覆盖更新原 SnowRead 并保留数据。
