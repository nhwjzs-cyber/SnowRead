- **目录**：搜索章节/卷名、点击卷名折叠/展开；回到当前章会清除搜索并展开所在卷。超过一万个标题会明确提示，正文仍完整可读。

本轮新增功能不增加权限；沿用系统听书所需的四项权限。包名、开发签名继续，书库格式仍为 3、备份格式仍为 2；书签备注使用可选字段，旧备份可读。

## 0.9 统一动效与系统听书 v1

本版按 docs/specs 内的两份 v1 文档实现，范围与差异说明见 IMPLEMENTATION-v0.9.md。

### 听书

打开小说 → 顶栏耳机图标（或“更多 → 听书”）→ 播放。默认从当前阅读位置开始，优先已安装的离线中文语音。未安装引擎或语音包时，面板提供系统设置、安装语音数据和重试入口；明确允许之后才使用需要联网的语音。

- 播放/暂停/停止，上一句/下一句、上一章/下一章、进度拖动，自动连播可选。暂停后从本句开头继续。
- 语速 0.5–2.0，0.1 步进，含 0.8/1.0/1.2/1.5/2.0 快捷按钮；系统引擎/语音选择及试听。
- 睡眠定时 15/30/60 分钟、本章结束或当前句结束；在句末暂停，不改系统音量。
- 句级高亮；API 26+ 引擎提供范围回调时使用词级高亮，压缩空白和去网址后仍映射到原文位置。可跟随滚动/翻页；手动浏览临时取消跟随，“回到朗读位置”恢复。
- 朗读范围当前阅读页/本章/全书；章节标题朗读、跳过独立页码、不读常见 ASCII 网址可选。数字行可能是真正文，请按需启用页码过滤。
- 书架底部迷你播放条，可暂停、停止或打开正在听的书。通知与媒体会话支持播放/暂停、切章、停止和返回；默认在锁屏隐藏书名。
- 系统音频焦点被暂时占用时暂停，可在焦点恢复时续播；永久丢失或用户暂停不自动恢复。耳机拔出立即暂停。
- 前台媒体服务在后台播放时使用通知，播放期间持有有超时保护的部分唤醒锁，暂停/错误/停止释放。允许熄屏；不申请电池优化豁免。
- 进程重建读取断点后保持暂停，不自动出声。书库、解码文档和 I/O 队列由 LibraryRepository 共享。听书会话接管该书进度，手动浏览不覆盖音频断点；点“停止”后交还阅读页。切换到另一册会停止上一册听书，避免长期保留两份整本解码文本。

Android 13+ 首次播放会申请通知权限。拒绝后可选择仅前台听书，离开应用即暂停；“语音设置与修复 → 申请通知/开启后台播放”可再设置。媒体通知存在系统豁免，不能把拒绝通知权限一概描述为锁屏控制必然不可用，设备表现需实测。

### 动效

统一 Motion 原语：120/180/220/240ms 令牌，工具栏 ±8、面板入场 32/退场 16、Toast 入场 12/退场 6、正文/结果列表 4 的轻位移配合淡入淡出；卡片按压 0.97，选中徽标及完成标记使用短缩放确认。面板回落不弹跳，原有 240ms 翻页算法和方向保持。

导入、备份/恢复使用细进度条；已知工作量显示确定进度，备份/合并按实际复制字节计量，解压校验总量未知时显示不确定线。进度渲染合并到最多约每 120ms 一次，后台任务不会按每个文件堆积 UI 更新。

开书/退书及主题预览使用有像素上限的旧页快照淡出，分配失败时直接显示最终页面；不逐帧重排文字。搜索结果整列淡入，无逐行动画。Toast 替换旧提示，3.2 秒后淡出。

“Aa 排版 → 减少动效”、系统关闭动画或触摸探索任一开启，直接进入最终状态；无需等待动画。窗口暂停、销毁和旋转时清理过渡。动效本身不需要新增权限或第三方库；四项新增权限只服务于听书。

### 实测边界

已通过构建、签名、纯 Java 听书核心和存储回归；尚未在手机运行 TTS、前台服务、通知、锁屏/蓝牙/来电、30 分钟持续播放或动效帧率。不能将代码完成等同于已达到这些设备验收指标。具体清单见 VALIDATION.md。

## 0.8.1 导入性能与单本快捷流程

- 同一次选择仅有一本 TXT 时，直接导入并自动打开，省去分类面板和汇总面板；若书已存在，打开原书并保留原进度。新书沿用当前自定义分类；当前为全部、置顶或未分类时默认不指定分类。
- 多本才进入分类、批量进度和汇总。逐本读取和保存正文，最终统一写一次完整索引；主动停止时也统一提交已经处理成功的部分。无新增（全部重复、全部失败或开始前停止）时不重写索引。
- 最终提交失败会撤回本批新增 Book、ID 缓存和本地正文文件，恢复原书架顺序，保留原索引、旧书进度、书签、分类和封面；汇总明确显示未保存和已撤回数量。个别文件失败继续处理其他文件。
- 使用按内容 ID 的查找表，在解码前识别重复；批量过程中追加新书，提交时一次构造最近导入优先的顺序，避免逐本移动整个列表。
- 批处理支持嵌套，只有最外层提交；导入过程中禁止其他修改书架的操作。忙碌时不因横竖屏回调重建书架，避免遍历尚未提交的数据。
- 采用统一提交后，完成/主动停止并成功保存才代表本批新增记录已持久化；进程被强制结束时，尚未提交的本批记录可能不会保留。原有书库不受影响。此处的“一次”仅指索引，正文仍需逐文件保存。

新增宿主事务测试直接统计索引 AtomicFile 写入次数：500 本新增仅一次，500 个重复项零次；并验证嵌套、停止、最终写入失败的内存/文件回滚及缓存恢复。手机导入速度还取决于文件大小、编码、存储和文件提供器，宿主测试不是手机性能承诺。

## 0.8 系统栏、面板交互、目录与多分类

- Activity 和自定义面板窗口统一 Edge-to-Edge，背景延伸至状态栏与导航栏，交互内容按系统栏、刘海和键盘避让。API 29+ 关闭系统额外对比度遮罩；面板白纸背景延伸至底部导航区。Android 6/7 不支持深色导航键，采用青蓝底配白键的兼容方案；输入法出现时其导航区由系统/输入法控制。
- 可关闭面板支持点击右上角 X、外部遮罩、系统返回键和跟手下滑；松手后根据距离/速度关闭，未达到阈值则回弹。列表已经向下滚动时，正文区域的下滑优先滚动列表，滑到顶部后再下拉可关闭；从标题区域可直接下拉。横向滑条和分类左滑保留各自手势。
- 去掉仅用于关闭的底部“关闭 / 完成 / 取消”按钮，保存、跳转、删除、输入章号等真正的操作仍保留。导入、导出和恢复等进行中的任务不支持误触遮罩或下滑打断；批量导入用面板内“停止导入”按钮停止。
- 目录右上角切换正/倒序，记住排序偏好；右下浮动准星按钮回到当前章。当前章青蓝高亮，当前位置之前的章节浅灰，之后的深色。此颜色按当前进度推断，不是逐章阅读完成历史；跳读后不会声称实际读过之前的章节。
- 底栏设置入口改为 **Aa 排版**。页边距可调 12–56，滚动和分页模式都生效；字号、行距松手后预览并保持文字位置。圆形原纸/暖纸/夜读色块点击即预览正文和示例背景，关闭面板后保存偏好。
- 分类管理列表左滑显示“重命名 / 删除”，也可点击展开，便于键盘或辅助功能操作。操作后列表及时刷新，取消确认仍回到管理面板。
- 一本书可归入多个分类。长按书籍 → 设置分类（可多选），或多选后点“分类”。✓ 表示所有所选书均属于该分类，— 表示部分属于；未修改的混合状态会保留。可清空分类；“保存选择并新建分类”会先保存已勾选项。
- 删除分类只解除对应关联，其他分类和书籍数据保留；仅剩最后一个分类被删除时才进入未分类。分类数量允许重复计入同一本书。
- 书库升级为 version 3，以 categories 数组保存每本书的分类 ID。可读取旧 JSONArray 和 version 2 单分类书库；旧记录自动保留为单个分类关联。新备份格式 2 支持多分类，仍能恢复 0.7 导出的格式 1 备份；旧应用无法读取新格式，请继续使用新版。

系统栏处理依据 [Android 官方 Edge-to-Edge 指南](https://developer.android.com/develop/ui/views/layout/edge-to-edge)，具体验证和设备边界见 VALIDATION.md。

## 0.7 批量导入、全文结果与备份

### 批量导入

点击书架底部“批量导入 TXT”，在系统选择器中长按或勾选多个文件，然后选择统一归入的分类。只选一本会直接导入并打开，不再弹分类或批量汇总。每批最多 500 个，每本仍限 12 MB。部分系统选择器只支持单选。

多本逐本显示处理进度；已导入过的原始文件按 SHA-256 跳过，已有书名、分类、进度不改动；不同编码或字节内容视为不同文件。某本失败不影响其他书；最后显示保存书架阶段，提交成功后汇总成功、重复、失败数量和原因，可以指定编码重新选择失败文件。点击“停止导入”会在当前文件完成后停止，并统一保存已处理成功的部分；最终保存失败则撤回本批新增。

### 正文搜索

阅读工具栏 → 搜索 → 输入关键词 → 点击“搜索”或键盘搜索键。列表显示章节、阅读百分比、命中点前后文，并高亮关键词；点击结果跳转至对应文字位置。支持清除阅读高亮。

搜索在后台进行，输入变更或面板关闭后放弃旧结果。按原文区分大小写、非重叠字面匹配；统计整本命中总数，最多显示前 1,000 条结果。命中很多时请用更具体的关键词。上下文预览避免截断 emoji 等 UTF-16 代理对。

### 备份与恢复

书架右上角“⋯” → “备份与数据管理”：

- **导出整库备份 ZIP**：选择保存位置，导出全部 TXT 原始副本、自定义封面、空分类和书籍分类、置顶、书名、编码、进度、书签。手机原始文件不需要仍在原位置。不包含阅读设置等界面个人偏好。
- **从备份恢复 / 合并**：选择应用生成的 ZIP，先检查路径、格式、数量、文件大小、正文 SHA-256、编码与文本长度、进度和书签位置；检查通过后显示数量和冲突情况，再选择合并方式。
- **保留当前记录**：同内容的书保留本机书名、封面、分类、置顶、进度和书签，备份中独有的书会添加。
- **采用备份记录**：同内容的书采用备份的上述记录，本机独有的书仍保留。分类同名时合并，分类 ID 碰撞但名称不同会重新分配 ID。

备份先在应用缓存中生成，再写入系统选择的位置。恢复先解压、校验并准备完整合并目录，再切换书库；切换中断后能从旧目录恢复。每份备份最多 5,000 本，解压后最多 1 GB，恢复时需要足够空间容纳备份和合并目录。ZIP 是明文备份，请保存在自己信任的位置。

长按书籍 → “导出原始 TXT”，可以单独保存一本文本，保留原始文件编码。文件与目录选择继续使用安卓系统选择器，其余面板沿用纸色与青蓝色自定义 UI。

格式与事务说明见 BACKUP_FORMAT.md。

## 阅读与书架

导入本地 TXT 后，文件副本、进度和书签存储在应用私有目录。每本书按文字位置恢复，字号或阅读模式变化时恢复到相应文字附近。TXT 单文件最大 12 MB，整本解码到内存，显示采用分块或按需分页。

阅读工具栏约 4 秒不触碰后自动收起；点击正文中间重新显示。按住、拖动进度、打开弹窗或失去焦点时暂停自动隐藏。工具栏是浮层，显隐不会改变正文区域大小。开启系统触摸探索时不自动隐藏。

支持上下滚动、逐页翻阅、字号和行距调整、原纸/暖纸/夜读、屏幕常亮、书签、正文搜索和高亮。

卷章标题应独立成行，例如“第一卷 相遇”“第十二章 夜色”。目录区分卷和编号章节；“目录 → 输入章号”可先选卷再跳转，全书同号时显示多个结果。

## 自定义封面与长书名

长按书籍可置顶、分类、多选、修改书名、选择自定义封面、恢复默认封面、切换编码或移出书架。

书名固定区域最多三行，字号在 13–17sp 内自适应，超长省略，大字体按实际高度减少可见行数。默认封面文字也按区域换行与缩放。

图片通过系统文件选择器导入，不申请相册全盘权限。原始图片不修改；后台采样、按可识别的 EXIF 方向校正并居中裁剪，保存为 480×720 JPEG。图片上限 20 MB、单边最多 40,000 像素。缩略图有内存缓存。

## 构建与检查

Android Studio 打开本文件夹，使用 JDK 17 或 21，安装 SDK Platform 35 / Build Tools 35.0.0 后同步 Gradle。AGP 8.9.2 / Gradle 8.11.1；首次同步需要联网。

    .\gradlew.bat assembleDebug

或使用本地 SDK 直接生成 RongxueReader-debug.apk：

    .\Build-WithSdk.ps1 -SdkRoot 'D:\Android\Sdk' -JdkHome 'C:\Program Files\Java\jdk-21'

公开开发签名位于 dev/debug.keystore，别名 androiddebugkey，密码 android。正式发布应配置自己的签名。

无需手机和 SDK 的核心检查：

    .\Test-Core.ps1 -JdkHome 'C:\Program Files\Java\jdk-21'

0.8 已执行文本/分页、工具栏/封面、分类/置顶、搜索与目录排序检查，算法保持不变。本次使用 Android Studio 的 layoutlib.jar 与 JVM 文件适配器执行书库升级、批量导入、备份往返及新增事务检查：

    .\Test-Storage.ps1 -JdkHome 'C:\JAVA' -LayoutlibJar 'C:\Program Files\Android\Android Studio\plugins\design-tools\lib\layoutlib.jar'

存储检查直接运行 LibraryStore 与 Android JSON 实现；tests/host 中的 AtomicFile 仅用于 Windows JVM 测试，不打入 APK，不等同于安卓设备文件系统验收。上述检查不代替 Android 动画、字体排版及触控验收。test-fixtures 内有长书名示例。验证记录见 VALIDATION.md。

## 已知边界

目录识别依赖标题格式，特殊格式可能需正文搜索定位。尚无仿真翻页、朗读、云同步及手动封面裁剪。分页模式不提供长按复制，滚动模式支持系统文字选择。首次定位长章节深处可能短暂等待。

卸载或清除数据会移除应用内副本、封面和进度，系统备份已关闭。请保留原始小说与图片。
